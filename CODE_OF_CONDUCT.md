# Code of Conduct

Geshtu adopts the **Contributor Covenant, version 2.1** as its
Code of Conduct, without modification.

The full text is the canonical reference and is published at:

**https://www.contributor-covenant.org/version/2/1/code_of_conduct/**

A plain-text copy is also distributed with the Contributor Covenant
project at https://www.contributor-covenant.org/. If anything in this
file ever appears to conflict with the canonical text, the canonical
text wins.

## Scope

The Code of Conduct applies to all project spaces — the GitHub
repository (issues, pull requests, discussions, code review), any
official chat channels, in-person and virtual events organized by the
project, and to anyone acting as an official representative of the
project in public.

## Enforcement

Reports go to **conduct@geshtu.io**. Reports are read by the
project lead (BDFL) and treated confidentially.

For the first 24 months of the project, the BDFL handles enforcement
personally, using the **Enforcement Guidelines** of the Contributor
Covenant 2.1 — published at the URL above — as the standard. The
escalation path is: private warning → temporary ban → permanent ban,
applied proportionally to the severity and pattern of the behavior.

After the 24-month governance review (see [GOVERNANCE.md](GOVERNANCE.md)),
enforcement may be delegated to a small response team. Any change
will be documented here.

## What to expect when you report

- Acknowledgment of receipt within 72 hours.
- A confidential conversation about what happened.
- A clear outcome: no action, a warning, a temporary ban, or a
  permanent ban.
- No retaliation against good-faith reporters. Reports made in bad
  faith — for example, to harass another contributor — are
  themselves a violation.

## Why we use the Contributor Covenant verbatim

The Covenant is the most widely understood baseline in open source.
Adopting it without edits means that contributors arriving from other
projects already know the rules, and that there is no ambiguity about
intent. We do not maintain a custom code of conduct because we do not
want to maintain one — the Covenant covers what we need.
